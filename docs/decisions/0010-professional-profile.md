# 0010 — Reviewed professional profile and autofill library

Source facts, canonical entries, and user-authored description variants are separate. All persistence uses the existing libSQL Db with workspace-scoped queries. Facts retain source file, section, kind, hash and review status; each canonical field points to the facts supporting it. Reviewer edits lose source attribution rather than falsely claiming evidence. Empty values mean unknown.

Deterministic YAML/Markdown and PDF text extraction runs locally without AI. Resume evidence is preferred for formal titles/dates/education, but disagreement always enters review. Combined employer entries are separated with ambiguous shared claims omitted. Extraction is deliberately conservative: an application_profile frontmatter object supports explicit structured records; prose extraction selects accomplished-work bullets from professional sections. It does not interpret source instructions or follow internal links or embeds. Wiki links are normalized as text.

The local adapter reads an explicit note allowlist beneath a configured vault root, rejects symlinks and traversal, and never writes source files. The HTTP adapter accepts selected file contents only and never reads server paths. Hosted users explicitly select professional files; no full-vault upload, directory picker, background sync, external AI or public source-file endpoint exists. Parser errors are redacted. Raw documents are not persisted by this feature, only extracted professional facts. The local adapter's private configuration and optional export belong in gitignored data/.

Synchronization hashes content, avoids reprocessing unchanged sources, deduplicates facts, supersedes pending suggestions from changed files and retains reviewed history. Changed canonical facts require explicit review. Source disappearance does not delete canonical history. User variants survive updates and can be compared with canonical defaults. Favorites, order and recent use belong to the library entry. Application events/status remain untouched.

Limitations: heuristic extraction requires human review; scans without embedded PDF text require OCR outside this feature. Role-specific variants are authored from reviewed facts or generated by selecting their exact sentences, never by a model. Local paths are references, not server-accessible links. Multiple stints at the same employer may need explicit merge-target selection. There is no automatic form filling or application submission.
